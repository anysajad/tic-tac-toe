# Tic Tac Toe 🎮

A premium, modern Tic Tac Toe web game designed with a clean, refined, iOS-inspired visual language.

The project focuses on making a simple classic game feel polished through thoughtful UI, smooth interactions, subtle motion, and responsive design.

## Modes

* 🤖 **AI / Computer** — Play against the computer.
* 👥 **Two Players** — Play locally with another player.

## Features

* Premium iOS-inspired interface
* Responsive design for desktop and mobile
* Local-first gameplay
* No backend required
* Smooth interactions and game feedback
* Simple and maintainable architecture
